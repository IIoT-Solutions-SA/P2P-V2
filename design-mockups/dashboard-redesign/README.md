# PeerLink dashboard redesign mockups

This folder contains three standalone HTML dashboard directions created before any React implementation work.

- `concept-a-command-center.html` — industrial and operational
- `concept-b-knowledge-desk.html` — editorial and community-led
- `concept-c-network-workspace.html` — collaboration and people-led
- `index.html` — comparison page linking all three concepts

The concepts share the same representative production data so layout and visual direction can be compared fairly. Each one treats **Find collaborators** as a capability for both members and administrators and keeps **Manage team** as a separate administrator action.

Open `index.html` in a browser, review every concept at desktop and mobile widths, and choose one direction or a deliberate combination before changing `p2p-frontend-app/src/`.
