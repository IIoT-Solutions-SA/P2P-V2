# PeerLink Forum Redesign Mockups

Static HTML mockup family for the forum experience, isolated from production React.

- `index.html` - forum listing, category browsing, search, filters, draft access and sidebar context.
- `thread-detail.html` - discussion detail, replies, nested replies, solved status and best-answer presentation.
- `composer-drafts.html` - post composer, formatting controls, autosave feedback and saved drafts.
- `states.html` - representative loading, empty and error states.
- `forum.css` and `forum.js` - shared Network Workspace styling and minimal mockup interactions.

These files intentionally reuse the selected Network Workspace dashboard/homepage visual direction: dark navigation rail, warm paper workspace, off-white operational panels, teal/blue accents, compact controls and responsive stacked layouts.
