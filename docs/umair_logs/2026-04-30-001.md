### 2. `p2p-backend-app/app/main.py`
**What I changed:** Added `"backend"` and `"p2p-backend"` to the `TrustedHostMiddleware` allowed hosts list.

```diff
  allowed_hosts=[
      "localhost",
      "127.0.0.1",
      "145.241.154.18",
      "peerlink.c4ir.sa",
      "p2p.iiotsolutions.sa",
+     ######################################
+     "backend",
+     "p2p-backend",
  ],
```

**Why:** When running inside Docker, the backend container is accessed by other containers using the hostname `backend` or `p2p-backend` (the Docker service name). Without these, health checks and inter-container communication would fail with a `400 Bad Request` from the TrustedHost middleware.
