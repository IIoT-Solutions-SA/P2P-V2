# **Use Case Submission – Machine Working Status Tracking**

---

## **1\. Basic Information Section**

**Title**  
 Machine Working Status Tracking

**Subtitle**  
 Centralized real-time machine status visibility improves efficiency and responsiveness

**Description/Executive Summary**  
 This use case provides real-time visibility into the operational status of all CNC machines on a centralized screen. The system tracks and displays the status of each machine — running, idle, or offline — enabling operators and supervisors to monitor the entire shop floor at a glance. By consolidating this information into a single dashboard, the factory improves efficiency, identifies bottlenecks, and ensures timely interventions when needed.

## **3\. Business Challenge**

**Industry Context**  
 CNC machines are critical to production workflows, and downtime directly affects productivity. Without centralized visibility, operators must manually check machine status, which wastes time and causes delays in detecting issues. This leads to inefficiencies, miscommunication, and slower response to shop floor disruptions.

**Specific Problems**

1. Lack of centralized view of CNC machine status

2. Delays in identifying idle or offline machines

3. Reduced productivity due to late interventions

**Financial Loss/Impact**  
 Estimated SAR 600,000 annual impact from lost productivity, delays, and underutilized machine capacity

## **8\. Challenges & Solutions**

**Challenge Name**: Data Latency in Early Rollout

* Description: Early system updates showed delays of up to 2 minutes in reflecting machine status

* Solution: Optimized network configuration and introduced local edge caching

* Outcome: Reduced latency to under 10 seconds for live status updates

**Challenge Name**: Operator Familiarity with Dashboard

* Description: Some operators struggled to interpret dashboard indicators initially

* Solution: Introduced training sessions and simplified dashboard design with clear color coding

* Outcome: 100% operator adoption achieved within 4 weeks

---

## **9\. Technical Architecture**

**System Overview**  
 IoT-enabled status tracking system capturing machine activity states (running, idle, offline) and displaying them on centralized dashboards for real-time monitoring.

**Architecture Components**

* Data Layer: IoT machine status sensors, edge devices

* Application Layer: Centralized monitoring software, data preprocessing engine

* Presentation Layer: Shop floor dashboards, supervisor workstations

**Security Measures**

* Encrypted communication between sensors and dashboards

* Role-based access for supervisors and operators

* Regular system maintenance and network audits

**Scalability Design**

* Modular sensor installation for additional CNCs

* Dashboard expansion to other machine categories

* Cloud backup for historical machine utilization analysis

## **11\. Lessons Learned**

**Category**: Process  
 **Lesson Title**: Visual simplicity drives adoption  
 **Description**: Initial dashboards were too complex, slowing operator adoption. Simplified visual indicators improved usability significantly.  
 **Recommendation**: Prioritize clear, color-coded dashboards for quick shop floor interpretation.
